## Tentang program

Program ini adalah contoh sederhana untuk mencatat pesanan di usaha laundry kiloan. Data yang disimpan meliputi nama pelanggan, berat cucian, harga per kilogram, dan status laundry.

Pada tugas ini, class `PesananLaundry` diperbaiki dengan menerapkan encapsulation. Properti dibuat `private`, lalu data diakses atau diubah melalui getter dan setter. Setter juga memeriksa data agar tidak diisi sembarangan.

## File program

- `PesananLaundry.php` berisi class utama.
- `index.php` digunakan untuk mencoba program.
- `test.php` berisi beberapa pengujian.
- `LAPORAN.md` menjelaskan perubahan yang dilakukan.

## Cara menjalankan

Pastikan PHP sudah terpasang di komputer. Buka terminal di folder ini, lalu jalankan:

```bash
php index.php
```

Untuk menjalankan pengujian:

```bash
php test.php
```

Jika perintah `php` belum dikenali, berarti PHP belum terpasang atau lokasinya belum masuk ke PATH. Hasil pengujian sebaiknya diambil setelah program benar-benar dijalankan di komputer sendiri.
